# 🎓 Degree Module Selector

A lightweight, mobile-friendly web tool designed to help engineering students easily choose elective modules (Complementary Studies and Technical Electives) and instantly track their credit requirements against degree thresholds.

## ✨ Features
* **Mobile-First Design:** Optimized card layout built for smooth smartphone and tablet usage.
* **Real-Time Calculations:** Automatically tallies up GE, TE, combined elective credits, and overall degree totals.
* **Visual Validation:** Highlights requirement thresholds in real-time as you check off modules.
* **Zero Dependencies:** Built using pure HTML, CSS, and JavaScript—no heavy frameworks or backend required.
